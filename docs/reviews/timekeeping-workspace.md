## How billing guidelines work

LegalWork saves the guideline’s text, rules, revision, effective date and linked record ID in the signed-in profile’s private timekeeping file on this device. Import extracts the source document’s contents. The original file stays in place. Firm, Client and Matter specify which work it covers. A firm guideline in this list applies to that person’s drafting across matters. A published firm policy is managed by an authorized billing administrator.

The service looks up eligible versions using the **service date**, selects one effective version at each applicable scope and resolves rules by field. A client guideline is available during initial reconstruction when the matter identifies a single visible billing client. For a matter with several billing clients, an explicit recipient identifies the client guideline during invoice wording review. Use a matter guideline for an instruction common to that matter’s recipients.

A guideline can change descriptions, terminology, proposed billable increments and wording checks during invoice review. For example, 17 recorded minutes with a six-minute round-up can yield a proposed 18 billable minutes. The booking service validates binding billing rules when the user accepts. Rules do not issue invoices, change hourly rates in a fee agreement or rearrange the time table.

The records-backed service supports synchronized time entries and existing invoice attachments. Full approval, pricing and issuance flows require a firm service that implements those operations. That distinction affects the actions visible in Billing settings and Invoices.

The [user guide](../user-guide/time-tracking.md) covers linking a guideline, reviewing a suggestion and working with either billing service.

## Manual review in LegalWork Dev

| User story | Steps | Expected result |
| --- | --- | --- |
| Open my time and change the period | Open Time tracking. Switch between Day, Week and Month, return to Today and leave the workspace open through a refresh. | Date, range and Time tracking settings appear above the table. Stopwatch is at the right. The table and timeline stay mounted through background reads. |
| Record and find time | Choose New entry. Enter a matter, description and minutes using a test entry. Search for the description, then clear search. | A same-period save joins the table. Recorded and Billable total the matching bookings. A different-period save has a link to its own date. |
| Change columns in an empty or populated table | Open Options, enable a hidden field, then visit another section and return. In the records table try Show archive, then Show active. | The selected header appears and scrolls into view, the default view remembers the choice, and the archive opens its own set of entries. |
| Record with either stopwatch | Choose a test matter and start the stopwatch from the app. Stop it from the floating control. Open the resulting block in Day timeline, choose Edit, change the description and Save. | The two controls share one timer. The editor opens inside Day timeline. The change updates the private suggestion. Booking requires a separate acceptance. |
| Delegate to my timekeeping chat | Ask the main Assistant to delegate “Review today’s timekeeping suggestions and summarize which entries need my input” to Timekeeping. Open Private chat. | The task reaches today’s regular chat. The normal composer, model picker, skills and attachments are available. Older days load on upward scroll when history exists. |
| Set the suggestion schedule | Open Settings → Time tracking. Choose Every hour or Daily and change a run time. Open Day timeline and choose Add suggestions on a day with test activity. | A completed check advances coverage, including a check that produces no suggestions. Reopening a day reads the saved result. The master switch pauses scheduled checks and activity capture. |
| Check mail and calendar evidence | Connect a test mailbox and its calendar in Integrations. In Settings → Time tracking enable those sources. Send a test reply and add an elapsed meeting with a distinct subject. Open that date and click the unchecked interval. | The agent can use the reply and meeting as evidence. A message arriving by itself supplies no worked minutes. The meeting and an independent overlapping activity can both be proposed. Inspect the drafts, then dismiss or accept each separately. |
| Observe work in another app | Enable Desktop activity in the desktop settings, open a test document in another app, and use it for at least a minute. Return to LegalWork and check the day. | The app records active intervals and shows the last observation time. A suggestion can cite that activity. Switching the source off excludes it from future checks. |
| Link a client’s rules | Open a test client in Back Office and choose Billing guidelines. Save a name, effective date and wording instruction. Reopen the same link, then open a different client’s link. | The first client shows its saved revision. The other client has its own list. The setting is available to the current profile on this device. |
