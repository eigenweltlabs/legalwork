# Back Office

Open **Back Office** from the global sidebar. Choose **Matters**, **Clients · Mandanten**, **People** or **Companies**. **Create** opens an editable record panel. Enter its name and press Enter or leave the field to save. Click a grid cell to edit it. Relation pickers connect existing records. Changes to views stay inside the current screen.

Use **Filter**, **Sort** and **Options** to control the table. Drag column headers to reorder them and drag their borders to resize them. Open the view name, such as **All Matters**, then **Save current view** to save your configuration. **Options > Show archive** displays archived records. Open a record's **Record options > Restore record** to restore it.

A matter can connect to several projects, and a project can connect to several matters. Open a matter's record panel and choose **Projects > Choose a project > Link**. In a project's Home screen, use **Matters > Link matter**, or **Create and link a matter** to start a new matter. Choose the client explicitly. Similar names do not automatically match clients or matters. Removing a link keeps the project and historical billing records. Projects can remain unassigned. Internal link tables are managed through these controls and do not appear as directory objects.

Open **Data model** to manage visible objects and fields. Choose an object, then **New field > select a type** to configure a custom field. Protected fields retain the types and relationships LegalWork needs. Labels remain editable. Changes affecting existing records show a review before applying. Changes that would invalidate stored values remain blocked. **Settings** edits the object's names. Custom objects can be archived and restored. **Add object** creates another directory type with a required Name field.

Use **More actions > Import CSV** to map columns and preview rows, warnings and errors before applying the batch. Matching Actaport IDs update existing records. A matching name alone keeps records separate. Relation columns accept an accessible record ID or `actaport:source-ID`, with `|` separating several references. Duplicate source IDs and unavailable relations are rejected. **Export CSV** includes only records and fields you may read.

**This computer** stores records locally. **Team** opens the firm's directory after a platform administrator enables Back Office sharing and grants the relevant permissions. **More actions > Publish to team** previews local records and possible duplicates before sharing. Shared project links require the project to be shared with that firm. Project permissions remain independent of matter links.

Offline record edits remain queued. Model changes require an online connection. The footer shows pending changes and sync errors. Open **changes pending** to compare your edits with the team version. **Apply my changes** reapplies the reviewed fields to the latest team record. If that record changes again, review it again. **Discard queued edit** removes that record's queued edits and reloads the team version after confirmation. If access is revoked, the managed replica is cleared while queued edits remain available for resolution. Signing out warns about pending changes.

The starter model includes fee agreements, time entries, billing items and invoices under **More** as data foundations. Currency amounts are kept separate by currency. A matter's value in dispute describes the case value. Private work notes, client-facing narratives and financial fields have separate access rules. Stopwatch, timesheet review and invoice issuance are later workflows.
