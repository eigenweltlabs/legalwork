Third-party notices for native OpenCode integration

The released OpenCode 2.1.4 engine supplies @opencode/plugin and Effect to
first-party plugins. No foreign SDK node_modules tree is staged. Desktop uses
the matching released browser RPC and a vendored MIT GUI controller. Versions
are pinned in package manifests and pnpm-lock.yaml. Other dependencies retain
their own license notices in the packaged dependency tree.
